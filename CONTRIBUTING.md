# Contributing

Dataset suggestions and corrections are welcome.

## Add or correct a record

1. Open an issue or a pull request with the dataset name and specialty.
2. Link the original dataset page. Add the descriptor paper or institutional page when available.
3. State what the reported count measures (patients, cases, images, scans, slides, or annotations).
4. Describe labels and modality using the source's wording.
5. Copy access and licence conditions from the provider. If unclear, write `Needs verification`; do not infer.
6. Include the date the source page was checked and any access or provenance caveat.
7. Search the existing catalogues for duplicates, mirrors, and augmented copies.

## Do not

- Upload patient-level data or source archives.
- Present a mirror, augmented copy, or model predictions as a new primary dataset.
- Claim a licence or public download status without a primary source.
- Include credentials, private links, or restricted files.

See [Sources and verification rules](SOURCES.md) and [Catalogue schema](catalog/SCHEMA.md).
